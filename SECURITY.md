# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report it privately instead: go to this repository's **Security** tab and click
**Report a vulnerability**. Only the maintainer can see the report.

Please include:

- what the problem is and where it is (file, endpoint, or setting)
- steps to reproduce it
- what an attacker could do with it

You'll get a reply within 7 days. Once a fix is out, I'm happy to credit you
in the release notes if you'd like.

## Supported versions

This is a personal project. Only the latest commit on `main` gets fixes.

## Found a leaked key?

If you spot an API key or token in this repo or its history, report it the
same way and don't use it.
